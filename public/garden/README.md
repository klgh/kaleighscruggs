# Garden post images

One folder per post slug (same name as the `.md` file in `src/content/garden/`).

```text
public/garden/<slug>/your-photo.jpg
```

In the markdown post, reference them like:

```md
![Short description of the photo](/garden/<slug>/your-photo.jpg)
```

Add as many images as you want — stack them between paragraphs in whatever order fits the note.
